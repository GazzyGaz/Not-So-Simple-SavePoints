# Error Reporting Checklist

Please include the following when reporting a Simple SavePoints problem:

- [ ] Simple SavePoints version and SM64 Co-op Deluxe version.
- [ ] Whether you were playing alone, hosting, or joining another player.
- [ ] Number of players and the mods enabled for everyone.
- [ ] Level, area, mission, and D-pad save slot used.
- [ ] Whether the save was loaded in the same area, from another area/level, or after restarting the game.
- [ ] What Mario, the camera, timer, enemy, held object, or ridden object was doing when saved.
- [ ] For a Bowser report: which fight, Bowser's action/health, whether anyone held him, and the tilt or missing-floor state.
- [ ] Exact steps that reproduce the issue, including what happened before saving and before loading.
- [ ] What you expected to happen and what happened instead.
- [ ] Whether it happens every time or only occasionally, and whether repeating the load makes it worse.
- [ ] Whether other players could see the same problem or experienced freezing, lag, duplicated objects, or timer changes.
- [ ] A screenshot or short video, especially if a script-error message appears.
- [ ] Relevant CoopDX log output, if available.

Before submitting, try once with only Simple SavePoints enabled. Do not share ROM files, passwords, or personal information.
